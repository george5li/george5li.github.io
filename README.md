# george5li.github.io

My portfolio — a little storybook: soft cottage colors, halftone dots and a pinch of Y2K.
Live at **https://george5li.github.io**

## Add a project / photo / video
1. Open `index.html`, find the `<div class="grid" id="grid">` section.
2. Copy any `<article class="card" ...>` block and paste it where you want it.
3. Set `data-cat` to `code`, `gamedev`, `photo` or `video` (the filter buttons use this).
4. Drop your image into `assets/` and use `<img src="assets/your-file.jpg" alt="what it shows">`.
   For videos, link a YouTube/Vimeo URL in the `more` link (or embed an `<iframe>` in the thumb).
5. Commit to `main` — GitHub Pages republishes in about a minute.

Tip: export photos at ~1600px wide JPEG (quality ~75) so the page stays fast.
